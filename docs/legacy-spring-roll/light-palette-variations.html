Light palette studies
14 Jul 2026

Four lighter takes on light mode.

The brief: a very slightly off-white ground, greens that aren't so heavy, and a secondary grey that doesn't pull as dark. Dark mode is untouched. Every card renders the same slice of the Tasks page in its own palette, with measured contrast ratios so lightness stays honest — muted is the schedule text, so it matters most.

One structural finding: the current greens are dark because solid buttons put white text on them (needs ≈4.5:1). Lighter greens read beautifully as links, dots, and active states — so each variation keeps a darker btn partner for filled buttons, and the light green does everything else. WCAG AA for small text is 4.5:1; 3:1 passes for large text and UI marks like the dots.
