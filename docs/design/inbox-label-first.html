Label first

Morning digest is the stable object you scan for. The changing response moves underneath and no longer steals the row’s identity.

02

Short receipt

The response is limited to roughly 56 characters and one line. The detail page carries the full answer; Inbox only needs recognition.

03

Switch, don’t stamp

The source switch remains useful for narrowing the feed. Repeating that distinction on every row is left off.
