Springroll design study

One family of cards.

The same provider, recipe, and run content in four reusable treatments. Only the container changes. Actual app colors; sample content. Hover the cards and try the buttons.

My suggested system

A for provider and recipe cards. A slightly different background groups the content without putting a box around everything.

D for repeated activity and settings rows. Use a single separating line where the surrounding list already provides structure.

C for menus and popovers. Elevation is most useful when something genuinely floats above the page. Keep outlined fields for dropdowns and inputs.

Reserve stronger outlines for keyboard focus, selection, or attention—not every resting card. Status text and icons should communicate meaning without relying on color alone.
