Surface 1

The glance

Ninety percent of interactions end here. Attention first, then the morning’s tape, then what’s next. Three seconds and close.

The glyph is the status surface: a resting clock, and a single amber dot when something needs you. It never animates, never bounces.

Non-events are typographically demoted — weight and tone, not hidden.

Surface 3

The run is a letter

The run-detail-letter direction, fully at home: first person, past tense, findings before drafts. A note from a competent assistant, not a log.

Drafts are the propose-then-act pattern made visible — quiet verbs, accent only on the affirmative.

Mechanics (tool calls, duration, cost) live in one faint footnote. Readable transcripts are the trust mechanism.

Surface 4

The sentence is the interface

One text box; the app answers with a proposal — schedule chip, connection chip, and the contract sentence, set in the serif because it’s a promise, not chrome.

“Run it once now” is the signature control: create → try → tune → schedule. Instant gratification instead of commit-and-wait; it doubles as the prompt debugger.

Connections arrive just-in-time — sign-in happens on first need, never as setup.

Run “App review sweep” when this Mac is off?

Right now this task only runs while your Mac is awake. Run anywhere lets our service run it on schedule when your Mac isn’t available.

To do that, we’d hold your App Store Connect access on our servers, encrypted, used only by this task. You can take it back any time — runs then stay on this Mac.

Surface 5

The one serious moment

Escrowing credentials is the app’s single consequential decision, so it gets a real sheet with honest copy — what we hold, where, and how to take it back.

“Keep it local” is a first-class answer, not a cancel. Per task, reversible, and the only place the service is ever mentioned by name.

Palette and rules inherited from the spring-roll system: warm greys on white / neutral #0f0f0f dark, tone before strokes, muted ≥ 6:1, faint for furniture only, monochrome state with one spruce accent and amber reserved for attention. “Rota” is a placeholder name.
