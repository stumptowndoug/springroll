# Design references

The retained style guide, card grammar, and chat flow explain the current design.
Shipped behavior is defined by `app/src/client` and `desktop/loading`.

Superseded design alternatives, old-brand mockups, and icon comparisons were
removed from the current tree in the September 6 public-repository cleanup.
Their history remains available in earlier commits; these experiments are not
part of the application package or maintained product documentation.
