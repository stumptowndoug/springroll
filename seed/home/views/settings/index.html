Coding agents

You chat with any of these from Springroll; each runs on this machine with full access by default (switch a chat to "Ask first" to approve actions). Install and sign-in open a terminal so you can finish the login there.

For anything else, ask the agent ("make lists denser", "use a serif for titles"). It edits /ui/custom.css or the kit itself; see every component in the Gallery.

Updates

This machine is your own version of Springroll. Each week an agent merges what's new upstream, keeps your changes, checks everything still works, and sends you what it took, adapted or skipped. Undo is one revert.

Backups

A backup is one file: your home repo with its history, your apps' data, and (encrypted) your keys and sign-ins. Move to a new machine with install.sh --restore <file>. The nightly backup job keeps the last 7 here; download one now and then to keep a copy elsewhere.

Keyboard

On a Mac these use Control, not Command, so they don't collide with the browser. Ask the agent to change them (ui/hotkeys.json).

Phone and install

Notifications: install the ntfy app and subscribe to …. Jobs, finished long chats and approvals land there.

Install Springroll as an app for a window without browser bars: Chrome's install icon in the address bar, Safari on Mac File → Add to Dock, iPhone Share → Add to Home Screen.
