Updates

This machine is your own version of Springroll. Each week an agent merges what's new upstream, keeps your changes, checks everything still works, and sends you what it took, adapted or skipped. Undo is one revert.

Keys
Show valuesReveal and copy keys on the Keys page

Off, every value stays masked in Springroll. Agents, apps and jobs still use the keys; this is only what shows on screen.

Backups

A backup is your home repo with its history, your apps' data, and (encrypted) your keys and sign-ins. The nightly job keeps the last 7 on this machine and, once you set it up, sends an encrypted copy to your own storage bucket. Move to a new machine with install.sh --restore <file> (or restore --offsite <bucket>).

Keyboard

On a Mac these use Control, not Command, so they don't collide with the browser. Ask the agent to change them (ui/hotkeys.json).
