Coding agents

Every agent runs in its own terminal session on this machine and keeps running when you close the Desk. Setting one up installs it and starts its sign-in in a terminal, so you can finish the login there. Agents can also call each other headless (see agents/agents.json).

Keyboard shortcuts

On a Mac these use Control, not Command, so they don't collide with the browser. Ask the agent to change them.

Phone notifications

Install the ntfy app and subscribe to …. The agent's notify command lands there.

Install

Install the Desk as an app so it opens in its own window without browser bars: in Chrome, the install icon in the address bar; in Safari on Mac, File → Add to Dock; on iPhone, Share → Add to Home Screen.
