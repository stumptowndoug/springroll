Views

Starting points the agent can build on. Adding one installs it; if it needs accounts or keys, an agent session walks you through setup. Or just ask the agent for something new.

Coding agents

Each agent runs in its own terminal session on this machine and keeps running when you close the Desk. Install and sign-in happen in a terminal tab so you can finish the login there.

Backups

A backup is one file: your home repo with its history, your Views' data, and (encrypted) your keys and sign-ins. Move to a new machine with install.sh --restore <file>. A nightly backup job keeps the last 7 here; download one now and then to keep a copy elsewhere.
