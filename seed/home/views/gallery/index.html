Page heading

Every page, in this order: ui-heading (eyebrow, display title ending with a period, one primary action on the right), an optional ui-lede (one or two sentences), an optional ui-pagebar (tabs and search), then the content. A page that holds a collection adds to it with one primary New … button in the heading; when an agent makes the thing (an app, a job, a connection) the button opens a chat (#/new?text=…). No dashed "add" tiles. Detail pages start with a back link.

Code and documents

Loaded on first use. await ui.codeBlock(text, {file}) highlights code in the theme's own colors; await ui.editor(el, {value, file}) is a small editor (prism-code-editor); await ui.document(markdown) renders a whole document, sanitized; ui.highlight(el) colors the code blocks ui.markdown leaves. The Files View uses all four.
