# Gallery

Every component in the AgentOS kit, live in the current theme, plus two
sample layouts: a tool View (list and detail) and a content View (display
title and prose). It's the reference for building Views: copy markup from
here. Static page; the kit lives in `views/desk/public/ui/` (`theme.css`,
`kit.css`, `kit.js`) and the rules in `~/home/DESIGN.md`.

When you add a component to the kit, add it here too.
